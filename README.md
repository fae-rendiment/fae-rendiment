# FAE · Àrea de rendiment

Plataforma web de l'àrea de rendiment de la Federació Andorrana d'Esquí.

Aquest repositori només conté el codi de la pàgina. **No hi ha cap dada aquí**: les dades dels corredors són a Firebase, protegides amb usuari i contrasenya i amb regles d'accés per rol (equip tècnic, entrenador/a, corredor/a).

- `index.html` — la plataforma
- `firestore.rules` — regles d'accés a la base de dades (còpia de referència; les actives són a la consola de Firebase)
